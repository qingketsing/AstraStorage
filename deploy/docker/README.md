# Docker Assets

This directory groups Docker-based local deployment assets.

## Active Directories

- `app/`: Dockerfiles for `mds`, `datanode`, and `gateway`
- `monitor/`: local Prometheus and Alertmanager stack
- `rabbitmq-cluster/`: local RabbitMQ cluster assets
- `redis-sentinel/`: local Redis Sentinel assets

## Intent

These assets are for local development, smoke testing, and reproducing infrastructure dependencies outside Kubernetes.
